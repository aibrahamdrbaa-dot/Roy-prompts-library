# Roy Prompts Library

A structured, searchable library of reusable AI prompts maintained for Roy.

## Organization

| Section | Purpose |
|---|---|
| `01-image-video` | Image-to-video, video generation, motion, animation |
| `02-image-generation` | Image creation, editing, composition, style |
| `03-product-visuals` | Product photography, ads, packaging, commercial visuals |
| `04-social-content` | Social posts, reels, carousels, hooks, captions |
| `05-writing` | Copywriting, rewriting, scripts, long-form content |
| `06-research` | Research, analysis, extraction, comparison |
| `07-automation` | Automations, workflows, integrations |
| `08-agents` | AI agents, tools, memory, orchestration |

## Prompt file convention

Every reusable prompt can have two companion files in the same folder:

- `.md` — the production prompt, metadata, use cases, and usage notes.
- `.txt` — a plain-text explanation of what the prompt does, how it works, and when to use it.
