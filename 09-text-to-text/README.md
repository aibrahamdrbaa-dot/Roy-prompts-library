# 09 — Text-to-Text

Text-to-text prompts for interactive reasoning, reflection, self-analysis, questioning, decision support, and structured thinking.

## Main subcategory

- `deep-reflection-thinking` — reflective, psychological-style, Socratic, adversarial, and problem-framing experiments.

## Rule

These prompts are designed as **interactive experiences**, not just one-shot answers. Many ask one question at a time and adapt to the user's responses.
