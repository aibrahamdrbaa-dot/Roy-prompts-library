# Experimental Dialogues

Text-to-text prompts designed as unusual interactive experiments rather than ordinary question-answering.

## What makes this category different

These prompts deliberately manipulate the **conversation process**:
- withholding the goal
- asking one question at a time
- changing roles
- forcing multiple perspectives
- generating a question before an answer
- testing how framing changes the answer
- using controlled two-pass reasoning
