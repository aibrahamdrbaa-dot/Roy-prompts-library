# Prompt

Give me a difficult problem.

Before answering it, generate 5 different interpretations of what the problem might actually be asking.

For each interpretation:
- identify the hidden assumption
- explain what answer it would produce
- explain how the answer changes

Do not solve the original problem yet.

First show me how changing the question changes the solution.

Then ask me which interpretation is closest to what I actually mean.
